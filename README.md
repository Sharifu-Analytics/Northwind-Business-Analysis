# 📊 Northwind SQL Business Portfolio

## Overview

This project showcases business-focused SQL analysis using the Microsoft Northwind sample database in PostgreSQL.

The goal is to solve real business problems by writing efficient SQL queries using joins, aggregate functions, Common Table Expressions (CTEs), and window functions.

This project is part of my Data Analytics portfolio.

---

# Project Objectives

The project answers the following business questions:

- How has monthly sales revenue changed over time?
- What is the cumulative (running total) revenue?
- What is the month-over-month sales growth?
- Who are the top customers in each country?
- How much revenue did each employee generate?
- Which employee generated the highest revenue each year?
- Which product category performed best each year?
- Which are the top 3 products in each category?
- Which employee generated the highest revenue in each customer country?
