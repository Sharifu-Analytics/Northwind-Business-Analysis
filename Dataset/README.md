# Northwind Dataset

## Overview

The Northwind sample database is a fictional business database created by Microsoft. It is widely used for learning SQL, database design, and business data analysis.

This project uses the PostgreSQL version of the Northwind database.

## Dataset Description

The dataset contains information about:

- Customers
- Orders
- Order Details
- Products
- Categories
- Employees
- Suppliers
- Shippers

These tables simulate the daily operations of a wholesale food distribution company.

## Purpose of This Dataset

The dataset was used to perform business-focused SQL analysis, including:

- Monthly sales revenue analysis
- Running total revenue
- Month-over-month growth
- Customer sales analysis
- Employee performance
- Product category performance
- Product ranking
- Regional sales analysis
